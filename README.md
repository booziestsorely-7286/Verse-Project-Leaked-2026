## 🕹️ About

Verse Project is a multiplayer space simulation from Synthes Games, set across a realistically scaled Solar System. Fly near-future spacecraft, explore planets, moons, and asteroids, mine resources, trade, and push into the struggle for space control. This repository contains a raw Windows pre-release build that surfaced before the finished game was ready.

For players who enjoy realistic space simulators, large-scale multiplayer sandboxes, exploration, trading, and unpolished builds that feel like they slipped out of the lab.

 **Q: Will this affect my official game install or saves?**
